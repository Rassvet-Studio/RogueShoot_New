# RogueShoot

Минимальная основа 3D FPS на Godot 4.4 для дальнейшего развития кооперативного рогалика.

## Запуск

1. Откройте `project.godot` в Godot 4.4.
2. Запустите проект (`F6` для текущей сцены или `F5` для проекта).

В окружении разработки проект проверен Godot 4.6.3; используется только совместимый с Godot 4 GDScript и стандартные узлы.

## Управление

- **WASD** — движение.
- **Мышь** — обзор.
- **Пробел** — прыжок.
- **Esc** — освободить курсор.
- **Esc** повторно или клик по окну — вернуть захват курсора.

Чувствительность мыши настраивается через `mouse_sensitivity` у `FPSPlayer` в `scenes/player/player.tscn`.

## Структура

- `scenes/main.tscn` — тестовый уровень, свет, окружение и экземпляр игрока.
- `scenes/player/player.tscn` — переиспользуемая сцена игрока.
- `scripts/player/fps_player.gd` — локальное FPS-управление.

Игроки уже выделены группой `players`; сетевой слой и идентификаторы игроков можно добавить позднее, не меняя базовую сцену уровня.
